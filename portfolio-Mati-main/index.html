Sobre Mí

Hola, soy Matías González. Soy desarrollador web full stack y estudio en el Instituto Superior Santo Domingo. Construyo aplicaciones completas: desde la base de datos y la API (Node.js, Express, MongoDB y PostgreSQL) hasta interfaces modernas y responsive con React, HTML, CSS y JavaScript. Me interesan también la ciberseguridad y el soporte IT, y sigo aprendiendo todos los días.
